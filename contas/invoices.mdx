title: "Cobranças Pix e boleto"
description: "Emissão de cobranças Pix, boleto e híbridas pela API de Contas, com pagador no pedido, PDF e webhook INVOICE."
---

Emissão de cobrança **Pix, boleto ou híbrida (`PIX_BOLETO`)** pela API de Contas. Não é a API Pix Bacen (`/cob`, `/cobv`) — essa está em [QRCodes](/qrcodes/jornada-cobranca).

Host: `https://secureapi.onz.finance/api/v2`. Escopos: `invoices.read` / `invoices.write`. Criação exige `x-idempotency-key` (máximo 50 caracteres). `pixKey` é obrigatória quando o método inclui Pix. Credencial BaaS envia `x-account-id`.
