Lista os leads do Crédito do Trabalhador disponíveis para a conta autenticada.

**Endpoint:** `POST /econsigado/employee/clt-leads/list`  
**Scope:** `econsignado.read`

```bash
curl --location 'https://secureapi.onz.finance/api/v2/econsigado/employee/clt-leads/list' \
  --header 'Authorization: Bearer <access_token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "page": 1,
    "per_page": 25,
    "status": ["NEW", "PROPOSAL_SENT"],
    "filter": "Maria",
    "created_at_from": "2026-08-01T00:00:00.000Z",
    "created_at_to": "2026-08-11T23:59:59.999Z",
    "sort_by": "created_at",
    "sort_order": "desc"
  }'
```

| Campo | Obrigatório | Descrição |
| --- | --- | --- |
| `page` | Não | Página (default `1`) |
| `per_page` | Não | Itens por página (1–100, default `25`) |
| `status` | Não | String única ou array. Valores: `NEW`, `PROPOSAL_SENT`, `PROPOSAL_ACCEPTED`, `PROPOSAL_REJECTED`, `EXPIRED`. Array aplica filtro `IN`. |
| `filter` | Não | Busca textual por nome do trabalhador ou CPF (com ou sem máscara) |
| `created_at_from` | Não | Início da janela em `created_at` (ISO-8601). Se enviado com `created_at_to`, deve ser `<= to`. |
| `created_at_to` | Não | Fim da janela em `created_at` (ISO-8601) |
| `sort_by` | Não | `created_at` (default), `request_valid_until`, `proposal_sent_at`, `status` ou `requested_amount` |
| `sort_order` | Não | `asc` ou `desc` (default `desc`) |
| `status` | Não | `NEW`, `PROPOSAL_SENT`, `PROPOSAL_ACCEPTED`, `PROPOSAL_REJECTED` ou `EXPIRED` |

## Campos que definem o envio

| Campo | Descrição |
| --- | --- |
| `requires_guarantees` | Quando `true`, envie duas propostas no mesmo request: uma com e outra sem garantias. Quando `false`, envie apenas uma proposta sem garantias. |
| `requested_guarantee` | Garantias oferecidas pelo trabalhador. É `null` quando ele não pediu propostas com garantias. |

Em `requested_guarantee`, os campos não oferecidos pelo trabalhador vêm como `null`. A proposta com garantias deve enviar apenas os campos não nulos.

`proposal_sent_by_me` indica se a conta autenticada já enviou proposta para o lead.
